# Interactive Map Visualizer (`src/viz/`)

**Owner:** Person 4 (`feat/p4-hmm-viterbi-viz`)  
**Scope:** Interactive Folium and standalone Leaflet.js HTML map rendering for ground truth, raw GPS, and reconstructed routes.

---

## 1. Visual Layer Architecture

Every interactive HTML map generated by `src/viz/folium_map.py` includes:

| Layer Name | Color / Style | Purpose |
| :--- | :--- | :--- |
| **Ground Truth Route** | Solid Green (`#27AE60`, 5px) | Benchmark reference sequence (.route) |
| **HMM / Viterbi Route** | Solid Blue (`#2980B9`, 4.5px) | Reconstructed continuous path |
| **Classifier-Only (Argmax)** | Dashed Red (`#E74C3C`, 3.5px) | Raw pointwise classifier predictions |
| **Raw GPS Observations** | Orange Points (`#E67E22`) | Input noisy GPS trajectory with timestamps |
| **Road Network (Context)** | Subtle Gray (`#888888`, 1.5px) | Local urban street geometry |

---

## 2. Interactive Features

- **Dynamic Layer Controls:** Toggle individual layers on or off.
- **Custom Embedded Legend:** Visual key clearly distinguishing each trajectory.
- **Auto-Fitted Bounding Box:** Automatic centering and zoom based on GPS trajectory coordinates.
- **Zero-Dependency Fallback:** Automatically generates standalone Leaflet.js maps if `folium` is not installed.
