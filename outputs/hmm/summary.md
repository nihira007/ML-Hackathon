## Section 5: Hidden Markov Model (HMM) & Viterbi Decoding

### 5.1 Hidden States Definition
In PathSnap, GPS observations arrive at $\approx 1\,\text{Hz}$ sampling frequency. At each observation time step $t \in [0, T-1]$, the state space is defined over the set of candidate road arcs $C_t = \{a_{t, 1}, a_{t, 2}, \dots, a_{t, K}\}$ generated by the spatial projection engine. Each candidate arc $a_k$ is a directed edge in the city road graph with known topological start node $u = \text{from\_node}(a_k)$, end node $v = \text{to\_node}(a_k)$, and metric length in meters.

### 5.2 Emission Probabilities
Emission log-probabilities $\log P(y_t \mid a_{t,k})$ quantify the likelihood of observation features given the road segment. Rather than relying solely on raw Euclidean distance, our emission formulation integrates the supervised ML classifier's posterior probabilities:

$$\log P(y_t \mid a_{t,k}) = w_{\text{emission}} \cdot \log\left(\max(p_{\text{model}}(a_{t,k} \mid x_t), \epsilon)\right)$$

- **Tuned Emission Scalar:** $w_{\text{emission}} = 2.0$ provides optimal balance between local feature discriminability and global topological consistency.
- **Epsilon Clipping:** $\epsilon = 10^{-7}$ prevents numerical underflow for low-probability candidates.

### 5.3 Transition Probabilities & Physical Motion Model
Transition probabilities govern physical vehicular motion between consecutive segments $(a_{t-1}, a_t)$ using the Newson & Krumm (2009) exponential distance discrepancy formulation:

$$\log P(a_t \mid a_{t-1}) = -\frac{|d_{\text{route}}(a_{t-1}, a_t) - d_{\text{gps}}(p_{t-1}, p_t)|}{\beta_{\text{effective}}}$$

1. **Same-Segment Transitions ($a_{t-1} == a_t$):** Discrepancy is zero ($\Delta = 0$), incurring no topological penalty.
2. **Direct Physical Adjacency ($\text{to\_node}(a_{t-1}) == \text{from\_node}(a_t)$):** Network path length equals segment length.
3. **Shortest Network Route Distance:** For non-adjacent segments, single-source Dijkstra path length is queried on the directed NetworkX metric graph with a search radius cutoff ($1000\,\text{m}$) and per-trip LRU caching (<0.01 ms warm).
4. **Disconnected Fallback:** If no valid topological path connects the two arcs within cutoff, a finite disconnect penalty ($\log P = -30.0$) is assigned, preventing Viterbi trellis breakdown.

### 5.4 Edge-Case Hardening
- **Missing / Empty Candidates:** If an observation has zero candidate arcs due to GPS outliers, candidate states are safely carried forward from $t-1$ with decayed probability.
- **Temporal GPS Dropouts ($dt > 3.0\,\text{s}$):** When time deltas exceed the gap threshold, transition tolerance is relaxed dynamically: $\beta_{\text{effective}} = \beta \cdot \sqrt{dt / 1.0}$.

#### Comparison Across Baseline Algorithms (`outputs/hmm/baseline_continuity.csv`):
- **Logistic Regression (L2):** Continuity jumped from **90.0%** to **100.0%** (+10.0%); Top-1 Accuracy: **49.0%** to **55.5%** (+6.5%).
- **Distance-Weighted KNN (k=15):** Continuity jumped from **89.4%** to **99.7%** (+10.3%); Top-1 Accuracy: **55.6%** to **64.1%** (+8.5%).

#### Key Findings on Where HMM Helped Most vs. Least:
- **Highest Improvement (Trip `00000052`):** Short trajectory with tight turns where GPS noise caused the classifier to flicker across parallel road segments. The HMM eliminated flickering, achieving **+21.5% continuity gain**.
- **Lowest Improvement (Trip `00000007`):** Long straight highway corridor where raw candidate perpendicular distance was already unambiguous (baseline continuity was already 94.6%).
